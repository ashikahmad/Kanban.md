# Example boards

Each folder here is a complete board you can open: pick it in the app, or view it read-only in any browser. They match the ways teams use Kanban.md, described in [Git and teams](../git-and-teams.md#ways-teams-use-it).

| Example | What it shows | View it |
|---|---|---|
| [`software-development`](software-development) | A sprint: bugs and features, a Review column with a checklist, decisions in the notes, a task waiting on another (**Blocked by**), results with links to docs | [Open read-only](https://ashikahmad.github.io/Kanban.md/app/?board=../examples/software-development/kanban.md) |
| [`orbit-product-board`](orbit-product-board) | Product and project work: one task per feature, deadlines, filtering by person, a few archived tasks | [Open read-only](https://ashikahmad.github.io/Kanban.md/app/?board=../examples/orbit-product-board/kanban.md) |
| [`personal`](personal) | A to-do list with subtasks, side projects with notes, and a journal where each task is an entry | [Open read-only](https://ashikahmad.github.io/Kanban.md/app/?board=../examples/personal/kanban.md) |
| [`ai-agents`](ai-agents) | A person and an AI agent on one board: Started and Finished dates set by the tools, notes that say where work stopped, Result notes, a `#needs-human` task | [Open read-only](https://ashikahmad.github.io/Kanban.md/app/?board=../examples/ai-agents/kanban.md) |

To edit an example, copy its folder into your own project (a `board/` folder works best) and pick it in the app.
