# Project board

This folder is the Kanban.md project's own board: what is done, what is in progress, what is planned, and ideas under consideration. It uses the same format as any Kanban.md project.

- **Read it on GitHub:** [`kanban.md`](kanban.md).
- **Open it in the app:** open `kanbanmd.html`, choose this `board/` folder.

| Column | Meaning |
|---|---|
| 💡 Ideas | Not committed to. Open for discussion. |
| 📋 Planned | Agreed, not started. |
| 🚀 In Progress | Being worked on now. |
| ✅ Done | Shipped. Older items move to [`archive.md`](archive.md). |

Look for the tags `#good-first-issue` and `#need-help` if you would like to contribute.

Use GitHub issues to report bugs and request features; the board is where maintainers record direction. See [Development](../docs/development.md#how-we-run-this-project).
