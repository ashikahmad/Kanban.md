A Kanban board that lives in plain Markdown

Kanban.md turns two Markdown files into an interactive board. The whole app is one HTML file that runs in your browser and reads and writes your folder directly. No server, no account, no database. Humans use the browser, AI agents use the command line, and both edit the same files.

Open the app Get the demo board See our own board

Works in Chrome, Edge, Opera and Brave on desktop. Your files stay on your machine.

The board, showing the sample data from docs/demo.

What you get

Everything is a file you can read, edit, diff and commit.

Your tasks, as files

Plain Markdown that works in any editor and displays properly in any Markdown viewer, including GitHub.

Fits in git

Edits are small line-level patches, so moving a card changes one line and diffs stay readable.

A real board

Drag-and-drop columns you define, subtasks with progress bars, priorities, tags, categories, assignees, due dates, search, filters, an archive, several projects, light and dark themes, and four interface languages.

Humans and AI together

A CLI and an MCP server let agents read and change the board safely while you use the browser. Changes show up on both sides within a couple of seconds, and concurrent edits are merged, not overwritten.

Cheap for AI

An agent reads a few hundred tokens instead of the whole board. A "what is in this column?" question on a 100-task board costs about 1,000 tokens instead of about 20,000.

Private by construction

Nothing leaves your machine. No telemetry, no CDN, works offline. This page loads no scripts or fonts from anywhere else either.

Where it fits

Where it shines

  • Developers who want tasks next to their code, in the same repository and the same pull requests.
  • Small teams who share a board through git.
  • Anyone working with AI coding assistants who wants a clear, traceable record of what was asked and done.
  • People who like owning their data and being able to open it in a text editor.

What it is not for

  • Not a hosted service. No accounts, permissions, notifications or live co-editing. Teams share a board through git or a synced folder.
  • Not a server or an API. Agents use the CLI and the MCP server; there is no HTTP API.
  • Not for every browser. It needs a Chromium-based desktop browser. Firefox, Safari and iOS are not supported.
  • Not a reporting tool. There are no charts or time tracking yet.

Try it

Nothing to install and nothing uploaded. The app reads and writes the folder you pick, on your machine.

  1. Open the app in Chrome, Edge, Opera or Brave.
  2. Pick a folder. If it is empty, the app creates kanban.md and archive.md for you.
  3. Want to look around first? Download the docs/demo folder and pick that for a sample board with dummy tasks.

Prefer a local copy? Download kanbanmd.html and open it in your browser. More options are in Getting started. Your browser may ask again for folder permission each session.

Use it with AI agents

The same operations are available from the shell as the kanbanmd CLI and through an MCP server.

npm run mcp:install      # once, inside this repository
claude mcp add kanban -- node /path/to/Kanban.md/mcp/server.js --dir /path/to/your/project

Copy AI_WORKFLOW.md into your project so your assistant knows the rules, and see Working with AI agents for the tools and per-assistant templates.
