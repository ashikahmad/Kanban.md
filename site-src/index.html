Kanban.md

A Kanban board that lives in plain Markdown

Two Markdown files become an interactive board. The whole app is one HTML file that reads and writes your folder directly: no server, no account, no database. You use the browser, your AI agents use the command line, and both edit the same files.

Open the app See the demo board

Editing works in Chrome, Edge, Opera and Brave on desktop; any browser can view a board read-only. Your files stay on your machine.

The demo board from docs/demo. We also run this project on our own board.

What you get

Everything is a file you can read, edit, diff and commit.

You and your agent, together

A CLI and an MCP server let agents change the board while you use the browser. Cards move within seconds on both sides, and concurrent edits are merged, not overwritten.

A roadmap your agent can afford

Agents read just the part they need. "What is in this column?" on a 100-task board costs about 1,000 tokens instead of 20,000.

Your tasks, as files

Plain Markdown that works in any editor and reads well in any Markdown viewer, including GitHub.

Fits in git

Edits are small line-level patches: moving a card changes one line, so diffs and reviews stay readable.

A real board

Columns you define, drag and drop, subtasks, priorities, tags, assignees, due dates, filters, an archive, several projects, light and dark themes, four languages.

You own everything

Nothing leaves your machine: no account, no telemetry, no CDN, works offline. This page loads nothing from anywhere else either.

Where it fits

✓Where it shines

  • Developers who want tasks next to their code, in the same repository and the same pull requests.
  • Small teams who share a board through git.
  • Anyone working with AI coding assistants who wants a clear, traceable record of what was asked and done.
  • People who like owning their data and being able to open it in a text editor.

–What it is not for

  • Not a hosted service. No accounts, permissions, notifications or live co-editing. Teams share a board through git or a synced folder.
  • Not a server or an API. Agents use the CLI and the MCP server; there is no HTTP API.
  • Editing needs a Chromium browser. Opening and editing your own folder needs Chrome, Edge, Opera or Brave on desktop. Firefox, Safari and iOS can still open any board from a web address, read-only.
  • Not a reporting tool. There are no charts or time tracking yet.

Try it

Nothing to install and nothing uploaded. The app reads and writes the folder you pick, on your machine.

  1. Open the app in Chrome, Edge, Opera or Brave.
  2. Pick a folder. If it is empty, the app creates kanban.md and archive.md for you.
  3. Want to look around first? Open the demo board read-only, in any browser. To try editing it, download the docs/demo folder and pick that.

Prefer a local copy? Download kanbanmd.html and open it in your browser. More options are in Getting started. Your browser may ask again for folder permission each session.

Use it with AI agents

The same operations are available from the shell as the kanbanmd CLI and through an MCP server.

# once, inside this repository
npm run mcp:install

# then register it with your assistant, e.g. Claude Code
claude mcp add kanban -- \
  node /path/to/Kanban.md/mcp/server.js \
  --dir /path/to/your/project

Copy AI_WORKFLOW.md into your project so your assistant knows the rules, and see Working with AI agents for the tools and per-assistant templates.
